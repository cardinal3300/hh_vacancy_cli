# hh-vacancy-cli

Программа для получения вакансий с платформы [hh.ru](https://hh.ru), их сохранения и удобной работы с ними: добавление, фильтрация, удаление и сортировка по зарплате.

## Возможности
- Подключение к API hh.ru и получение вакансий по поисковому запросу.
- Сохранение вакансий в JSON-файл.
- Получение топ-N вакансий по зарплате.
- Фильтрация вакансий по ключевым словам в описании.
- Удаление вакансий из файла.
- Простое взаимодействие через консоль.

## Архитектура
- `JobAPI` — абстрактный класс для работы с API сервисов вакансий.
- `HeadHunterAPI` — реализация для платформы hh.ru.
- `Vacancy` — класс для работы с вакансиями (название, ссылка, зарплата, описание). Поддерживает сравнение по зарплате.
- `Saver` — абстрактный класс для работы с хранилищем.
- `JSONSaver` — реализация хранения в JSON-файле.
- `utils` — фильтры и сортировка вакансий.
- `main.py` — консольный интерфейс пользователя.

## Требования
- Python 3.10+
- requests
- pytest (для тестов)

Установить зависимости:
```bash
    pip install -r requirements.txt
```
