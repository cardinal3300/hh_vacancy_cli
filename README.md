# HH Vacancy CLI

Консольный инструмент для поиска и управления вакансиями с платформы [hh.ru](https://hh.ru).  
Проект реализован на Python с использованием ООП, абстрактных классов и работы с JSON.

---

## Возможности

- Получение вакансий с hh.ru по ключевому слову
- Сохранение вакансий в JSON-файл без дубликатов
- Фильтрация вакансий по ключевым словам
- Сортировка вакансий по зарплате
- Вывод топ-N вакансий
- Человекочитаемый интерфейс в консоли

---

## Структура проекта

    hh_vacancy_cli/
    │
    ├── data/ # Данные и JSON-файлы
    ├── src/ # Исходный код проекта
    │ ├── api_base.py # Абстрактный класс API (JobAPI / Parser)

    │ └── utils.py # Вспомогательные функции (сортировка, фильтрация, топ-N)
    ├── tests/ # Тесты
    ├── main.py # Точка входа
    ├── README.md
    ├── pyproject.toml
    └── ...

## Установка и запуск

1. Клонировать репозиторий:

```bash
    git clone <repo_url>
    cd hh_vacancy_cli
```
2. Установить зависимости:

```bash
    pip install -r requirements.txt
```

3. Запустить программу:

```bash
    python main.py
```

4. Следовать инструкциям в консоли:

- Ввести поисковый запрос для вакансий

- Указать количество вакансий для загрузки

- При желании ввести ключевые слова для фильтрации

- Указать топ-N вакансий для вывода

## Принципы реализации

- Используются абстрактные классы и наследование (`api_base.py`, `saver_base.py`)

- Приватные атрибуты и методы для валидации

- `__slots__` для экономии памяти

- Магические методы сравнения вакансий по зарплате

- Все функции и методы типизированы

- Минимальные принципы SOLID соблюдены

---

## Примечания

- Для работы с API hh.ru используется библиотека `requests`

- JSON-файл добавляет новые вакансии без удаления старых

- Возможность расширения: поддержка CSV, Excel, базы данных

- Интерфейс полностью человекочитаемый, без вывода коллекций
